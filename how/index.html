one market. modular genesis.

Onemod is a launch layer that changes how a token begins without asking traders to leave Pump.fun. Every launch publishes its configuration before execution and produces a receipt the market can verify.

01

commit the manifest.

The creator selects the launch rules once. Supply, creator buy, timing, fee routing and optional protections are hashed into one signed manifest before deployment.

02

keep the market.

Onemod does not create another isolated venue. The configured token routes into Pump.fun, preserving the liquidity, traders and distribution that already exist.

SPYx$COIN
quoted in the pair you pick, from the first trade
03

remove block-zero privilege.

The creator cannot attach a private bundle to the deployment transaction. Mint details remain sealed until execution, so the creator enters under the same published rules as everyone else.

04

make every rule explicit.

Ticker, image, social provenance and launch parameters are checked before execution. The interface shows what is enforced, what is optional and what no system can guarantee.

05

route value by module.

Fee behavior is chosen before launch. A project can route value into buybacks, burns, liquidity or a public treasury, with every movement attached to the genesis receipt.

06

verify the genesis.

The final receipt links the signed manifest, deployment wallet, mint address, executed modules and transaction signatures. Anyone can audit the token from its first block.
